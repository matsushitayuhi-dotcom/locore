# Locore v2 コンセプト（ドラフト）

> 2026-09-03 作成。2026-09-05 留学特化リポジショニングを反映。確定したらこのドラフト表記を外す。

## 一言で

**海外留学の在学生・アルムナイ相談 / 伴走マーケットプレイス** — 海外大学に「いま通っている」「かつて通った」日本人の知見を、個人が30〜60分のオンライン相談（＋継続伴走）で買える場所。

- **主力**: 大学院・MBA（高単価。30分 ¥4,000〜6,000 / 60分 ¥8,000〜12,000）
- **コア**: 学部出願（30分 ¥3,500〜）
- **間口**: 語学・交換留学（30分 ¥3,000〜。最初の接点として）

## 何が変わったか（v1 → v2 → 留学特化）

| | v1（旧） | v2（相談ピボット） | v2.1（留学特化） |
|---|---|---|---|
| 商品 | 旅行記事（コンテンツ販売） | スポット相談（時間販売） | 留学相談＋継続伴走（**時間販売は不変**） |
| 買い手 | 中〜上級旅行者 | 海外準備を控えた個人（広い） | 留学志望者（学部・大学院・MBA・語学交換） |
| 売り手 | 在外邦人ライター | 在外邦人エキスパート | 海外大学の**在学生・アルムナイ**（在外邦人供給の部分集合） |
| 信頼の担保 | 居住認証 + AIモデレーション | 居住認証 + 相談後レビュー | 居住認証（在学・勤務の実態確認）+ レビュー（**不変**） |

特化の理由：広い「海外相談」は課題も支払い意思もバラける。留学（特に大学院/MBA）は (1) 締切がある＝行動が速い、(2) 予備校に数十万円払う層＝支払い意思が高い、(3) 「いま通っている先輩」の情報優位が明確、の三拍子。

## 差別化（誰の代替か）

- **プロ予備校・出願コンサル**: 出願テクニックの一般論と代行。高額（数十万円〜）で、入ってからの授業・研究室・生活のリアルは持っていない。Locoreは「いま通っている人のLIVE情報 × 1対1」を1回¥3,000〜で。
- **合格体験ブログ・YouTube**: 古い（数年前の制度・カリキュラム）・一方通行。「あなたの場合」には答えない。Locoreは今年の情報で、双方向で、伴走まで。
- **SNSのDM相談**: 無料だが返ってこない・相手が本物か確かめられない。Locoreは居住認証（書類で在学・勤務の実態確認）と確実な時間確保。

## MVPフロー（不変）

1. 相談者がエキスパート一覧を国・テーマで検索
2. プロフィール＋相談メニュー（30分/60分、料金、得意分野）＋経歴（在学中/アルムナイ）を見る
3. （任意）事前チャットで質問 → 空き枠から予約リクエスト
4. エキスパート承諾 → Stripeで事前決済 → Meetリンク自動共有
5. オンラインセッションを実施（単発 or 継続伴走）
6. 相談者がレビュー（★＋コメント）→ エキスパートへは月次で送金（MVPは手動）

## MVPで作らないもの

- ビデオ通話の自前実装（Meet/Zoomリンクで十分）
- Stripe Connect自動送金（件数が増えてから）
- 記事・コミュニティ機能の刷新（凍結して非表示、削除しない）
- 多言語対応（日本語のみ継続）

## 拡張メモ（同じ供給での横展開）

在外邦人という供給源は留学に限らない。留学で信頼とオペレーションを確立した後の横展開候補：

- **富裕層の海外移住・投資家ビザ**（ゴールデンビザ・タックスプランニングの「現地で実際にやった人」相談。高単価・同じ居住認証で成立）
- 駐在帯同・海外就職など、旧・広域コンセプトのテーマは需要が実証されたものから再導入

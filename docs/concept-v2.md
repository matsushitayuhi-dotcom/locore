# Locore v2 コンセプト（ドラフト）

> 2026-09-03 作成。ステップ0「コンセプト1ページャー作成」の叩き台。確定したらこのドラフト表記を外す。

## 一言で

**ビザスクの海外版（B2C）** — 海外に住む日本人（在外邦人）の「現地で暮らしているからこそ知っていること」を、個人が30〜60分のオンライン相談で買えるマーケットプレイス。

## 何が変わったか（v1 → v2）

| | v1（旧） | v2（新） |
|---|---|---|
| 商品 | 旅行記事（コンテンツ販売） | スポット相談（時間販売） |
| 買い手 | 中〜上級旅行者 | 移住・留学・駐在準備・旅行を控えた個人 |
| 売り手 | 在外邦人ライター | 在外邦人エキスパート（**不変**） |
| 信頼の担保 | 居住認証 + AIモデレーション | 居住認証（**そのまま核になる**）+ 相談後レビュー |

ピボットの理由：記事は「書く負担が大きく、売れるまで報われない」。相談は在庫不要で、聞き手の個別事情（子連れ移住、犬連れ、特定の学校…）に答えられる。記事では拾えないロングテールの質問こそ現地在住者の価値が最大化する。

## ビザスクとの違い

- ビザスクは**B2B**（企業のリサーチ、1時間1.5〜5万円、法人営業で成立）。Locore v2は**B2C**：個人が払える価格帯（30分¥3,000〜5,000目安）で、暮らし・手続き・現地感覚という「ビジネスにならない相談」を扱う
- 供給側の審査は経歴ではなく**居住実態**（居住認証済みバッジ）
- 競合らしい競合：ココナラ（総合すぎて現地性の信頼がない）、SNSのDM相談（無料だが返ってこない・信頼できない）。「本当に現地に住んでいる人に、確実に時間をとってもらえる」が差別化

## MVPフロー

1. 相談者がエキスパート一覧を都市・カテゴリで検索
2. プロフィール＋相談メニュー（30分/60分、料金、得意分野）を見る
3. （任意）事前チャットで質問 → 空き枠から予約リクエスト
4. エキスパート承諾 → Stripeで事前決済 → Meetリンク自動共有
5. オンライン相談を実施
6. 相談者がレビュー（★＋コメント）→ エキスパートへは月次で送金（MVPは手動）

## MVPで作らないもの

- ビデオ通話の自前実装（Meet/Zoomリンクで十分）
- Stripe Connect自動送金（件数が増えてから）
- 記事・コミュニティ機能の刷新（凍結して非表示、削除しない）
- 多言語対応（日本語のみ継続）

# ブログ（集客コンテンツ）の参考サイト調査 — 2026-09-06

対象: `/articles`（一覧）と `/articles/[id]`（記事）。エキスパートが書く記事を「検索から来た人が読んで、その先輩に相談する」導線にしたい。

## 0. いまの Locore の何がイケてないか

| 箇所 | 現状 | 問題 |
| --- | --- | --- |
| 一覧ヒーロー | 黒背景に万年筆の写真、巨大見出し「現地からの、読みもの。」、検索フォーム 3 つ＋「読む」ボタン | 旅行時代の世界観のまま。白基調・ライムの /experts と別サイトに見える。検索フォームが主役で、記事が最初の画面に 1 本も見えない |
| 一覧カード | ページ下に流れてくる | ヒーローが画面を占めて記事に辿り着かない。著者（先輩）が見えない |
| 記事ヒーロー | 全画面の写真＋中央寄せ巨大タイトル＋粒子アニメーション | 「読む」より「演出」。留学の実務記事にはノイズ |
| 本文 | クリーム地、中央 1 カラム | 読めるが、見出し・引用・箇条書きの書式が弱い。目次なし |
| 著者ブロック | 「居住認証済み」バッジ、旅行時代の文言、大きな矢印 2 つ | 在籍確認に未更新。相談 CTA はあるが、記事の途中に無い |
| 関連導線 | なし | 同じ先輩の他記事・同じテーマの記事・同じ国のエキスパートに流れない |

一言でいうと「雑誌の表紙を毎回めくらされる」構造で、集客コンテンツに必要な「検索 → 記事 → 著者 → 相談」の最短導線が無い。

## 2. 共通して見えたパターン

一覧:
- 先頭 1 本を大きく、以降は同じ文法のカード（Notion / ADPList / Every）
- カテゴリはタブで切り替え、URL に残す（Linear / Notion / ADPList）
- 著者を出すサイトは「顔＋名前＋肩書」を必ずセットで（Stripe / Every / ADPList）
- 見出しの下に 1 行のサブタイトル（Lenny's）。留学記事は「何が分かるか」を 1 行で言うと検索流入に効く
- 特集・連載で束にする（サイボウズ式 / SmartHR）

記事ページ（各サイトの記事を見た範囲の共通項）:
- ヒーローは写真ではなく「カテゴリ → タイトル → サブタイトル → 著者行（顔・名前・肩書・日付・読了時間）」の縦組み。画像はその下
- 本文は 640〜680px の 1 カラム、見出し 2 段階、引用、箇条書き、画像キャプション
- 長い記事には目次（Stripe の一部、Notion）
- 末尾に著者カード＋関連記事。ADPList は末尾でメンター探しへ

## 3. Locore への提案（方向）

「Intro 型の /experts と同じ白基調・ライム・角丸 12px」で、**著者 = 先輩を主役にした雑誌**にする。

### 3.1 一覧（/articles）

1. ヘッダー: 小さな見出し「先輩の読みもの」＋ 1 行の説明＋テーマタブ（得意分野の第 1 階層と同じ 9 つ）＋国チップ。黒ヒーローと検索フォームはやめる
2. 先頭 1 本を大きく（画像 16:9・カテゴリ・タイトル・サブタイトル・著者行）
3. 以降は 3 列カード（画像・カテゴリ・タイトル・著者の顔＋名前＋学校・日付）。画像が無い記事は黒地に記事種別の面（発信・メディアと同じ）
4. 段構成: 最新 → 「先輩別」（Every 式、書いている人ごとに 3 本）→ テーマ別 3 件ずつ
5. 各カードのホバーで「この人に相談する」が出る（/experts のカードと同じ振る舞い）

### 3.2 記事（/articles/[id]）

1. 全画面写真をやめ、縦組みヒーロー: カテゴリ・国 → タイトル → サブタイトル → 著者行（顔・名前・学校＋在学/卒業・在籍確認済み・日付・読了 N 分）
2. 本文 660px、見出し・引用・箇条書き・画像キャプションの書式を整える。長文は右に目次（PC）
3. **本文の途中（1/3 あたり）に小さな著者カード**「この記事を書いた先輩に 30 分で相談」— 読み終わる前に離脱する人を拾う
4. 末尾: 著者カード（在籍確認・得意分野・最安メニュー・直近の空き）→ 同じ先輩の他記事 → 同じテーマの記事 → 同じ国のエキスパート 4 人
5. モバイルは下部固定バーに「◯◯さんに相談する」

### 3.3 データ・運用

- 記事に `subtitle`（1 行要約）と `topic`（得意分野の第 1 階層）を持たせる。今の articleType（spot_guide / itinerary / expat_info）は旅行時代のもので留学記事に合わない
- 読了時間は本文の文字数から計算（日本語 500 字/分）
- 執筆画面（/writer/articles/new）も同じ書式で書けるようにブロックを整理する（次のテーマ）

## 4. 次のステップ

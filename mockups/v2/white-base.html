変更するトークン — 新旧値一覧

apps/web/app/globals.css（source of truth: packages/ui/src/styles/globals.css）

変更は neutral 系の4値＋運用ルール2点のみ。primary（ライム）・secondary・semantic 色はすべて据え置き。エイリアス（--color-bg / --color-surface-muted / --color-border …）は参照先が変わるだけなので触らない。

globals.css — token diff
トークン旧新意図・使いどころ
--color-neutral-25= --color-bg（ページ地） #F4F4EF → #FFFFFF 地を白に。「もっさり」の主因を除去し、ライムの発色を立たせる。
--color-neutral-50= --color-surface-muted（bg-muted） #ECECE4 → #F4F4EF 旧地色を「淡い面」に降格。テーマチップ地・入力地・muted 帯で cream の温かみを残す。
--color-neutral-100= --color-border #E7E7E0 → #E3E3DA 半段強め。白地×白カードで輪郭が消えないように。
--color-neutral-200= --color-border-strong #D8D8CF → #CCCCC1 同上（セレクト枠・アウトラインボタンの視認性維持）。
--shadow-xs ほか影トークン 値は変更なし 運用変更: .locore-card / ExpertCard に shadow-xs を標準付与。白地では罫線だけだと平板になるため、影で層を作る（hover は従来の -translate-y + shadow-md のまま）。
セクション区切り トークン変更なし 運用変更: 現行の「cream 地 ⇄ bg-card 白帯」交互は白地では効かない。「白 ⇄ bg-muted 帯」＋ border-y に置き換え（how it works・trust 等）。ハイライト帯は従来どおり bg-primary-50 グラデが使える。
--color-primary-*（ライム）ほか すべて据え置き CTA・バッジ・選択状態のライム、semantic（warning / info / danger）は変更しない。メールテンプレの地も cream #FAF5EB → 白へ（notifications-slice.html 反映済み）。
